VS 7X OPTION ENGINE
===================

GitHub + Streamlit Community Cloud ready.

FILES
-----
VS_7X_OPTION_ENGINE.py
START_VS_7X.bat
requirements.txt
vs_7x_logo.png
README_VS_7X.txt

RUN LOCALLY
-----------
1. Install Python 3.10+.
2. Open this folder in Command Prompt.
3. Run START_VS_7X.bat

OR

pip install -r requirements.txt
streamlit run VS_7X_OPTION_ENGINE.py

GITHUB / STREAMLIT
------------------
1. Create a new GitHub repository.
2. Upload all 5 files to the repository root.
3. Open Streamlit Community Cloud.
4. Select the GitHub repository.
5. Main file: VS_7X_OPTION_ENGINE.py
6. Deploy.

IMPORTANT
---------
This is a fresh VS 7X Option Engine UI shell.
Legacy VS FLOW trading logic, scanners and backend are not reused.
The supplied logo is used only as the VS 7X branding asset.
Live market/option-chain data must be connected to a verified data provider before live trading use.
